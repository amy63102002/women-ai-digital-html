UNIT 01

AI 工作力與 ChatGPT 基礎

30 分鐘
目標｜理解 ChatGPT 不只用來問問題，也可以成為工作流程中的數位助理。
行政／資料整理整理資訊、歸納重點、建立清單。
企劃／文案釐清想法、改寫內容、規劃溝通。
求職／客服／創業陪練分析情境、模擬對話、整理下一步。

暖身 Prompt

請一次問我一個問題，用 5 個問題了解我的工作經驗、擅長能力，以及我目前想找工作、接案或創業的方向。
學員實作
完成 5 題對話，選出一件「這兩天最想讓 AI 幫忙的工作」。
完成成果
UNIT 02

ChatGPT 工作實戰

90 分鐘
目標｜把一次性的問答變成可重複使用的工作方式：交代清楚、追問、修正、保存模板。

五段式交代工作

1. 我是誰必要背景
2. 我要做什麼明確任務
3. 給誰看指定受眾
4. 資料／限制事實與邊界
5. 我要什麼結果長度、語氣、格式

模糊版

幫我寫招生文。

工作版

我是一位剛開始接案的美甲師，主要客群是 30～45 歲女性。我要推出第一次體驗方案，價格 999 元。我要放在 Facebook。文字自然，不要像廣告。請控制在 300 字內，最後邀請對方私訊預約。

常用修正句

太正式，改成像真人說話。
字太多，縮短一半。
不要重寫全部，保留我的原句整理。
先不要回答，請先問我 3 個問題再開始。

一份資料，多種用途

原始資料→FB→LINE→FAQ→口播
學員實作
選自己的真實工作情境，完成一輪「下指令 → 看結果 → 追問修正 → 存成模板」。
UNIT 03

求職、接案與創業應用

60 分鐘
目標｜把過去經驗整理成市場看得懂的能力，並選出一條要深化的主線。

職缺分析

請分析這份職缺：核心能力、必要條件、加分能力、日常工作內容、履歷最應強調的經驗，以及我還需要補強的能力。

履歷整理

以下是我的真實工作經歷。請根據這個職缺幫我重新整理履歷內容。不可以幫我新增沒有做過的經驗。

能力盤點

我做過行政 8 年、活動安排、客戶服務、Excel、Canva，也經營過 Facebook。請幫我分析這些經驗背後有哪些可以被市場使用的能力。
學員實作
A 求職：做真實職缺能力對照；B 接案：盤點能力並選一個方向；C 微型創業：整理服務與客戶問題。
UNIT 04

ChatGPT ＋ AI 圖文

60 分鐘
目標｜把主題轉成對外看得懂的內容，並讓服務名稱、介紹與視覺素材可以在 DAY 2 繼續使用。
服務／主題→社群文→視覺方向→AI 圖→LINE 訊息

社群文 Prompt

我要推出＿＿＿服務。對象是＿＿＿。請幫我寫一篇 Facebook 貼文，從客戶真實生活情境切入，不要像硬廣告。

視覺企劃 Prompt

根據這個服務，給我 3 種宣傳圖片方向。每個方向說明主畫面、人物、場景、氛圍，以及圖片最適合保留的一句文字。

LINE Prompt

根據這張宣傳圖與服務內容，幫我寫一段 100 字內的 LINE 推播訊息。
UNIT 05

NotebookLM 個人知識庫

90 分鐘
目標｜把自己的資料整理成可查找、可引用、可延續使用的小型知識庫。
ChatGPT偏向協作、生成、企劃與互動。
NotebookLM偏向根據你提供的資料整理與問答。

可放入的資料

  • 履歷
  • 課程資料
  • 工作 SOP
  • 公司文件
  • 產品／服務介紹
  • 自己寫過的文章

練習問題

幫我整理這些資料裡最重要的 5 個主題。
根據資料，整理常見問題。
如果我要向完全不懂的人介紹，應該怎麼說？
安全提醒
課堂資料先移除個資與不宜公開內容；回答要能回到來源，不把未提供的內容當成事實。
UNIT 06

數位服務系統需求單

30 分鐘
目標｜把第一天成果轉成 DAY 2 Vibe Coding 可以直接使用的系統規格。

從人話變成系統規格

人話「我想讓客人用 LINE 預約一對一諮詢。」
服務名稱→價格→名額→姓名／電話→預約時段→狀態→通知

DAY 2 直接使用的 8 項規格

  1. 商品／服務名稱與簡介
  2. 價格
  3. 庫存／名額
  4. 客戶需填寫的資料欄位
  5. 訂單／預約狀態
  6. 管理員通知文字
  7. 客戶通知文字
  8. Rich Menu 主要動作
重要
這一階段只整理商業需求，不填 LINE Channel Secret、Access Token 等技術憑證。
